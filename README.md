# Spandana 2026 - College Event Portal

A responsive college fest portal built with **HTML5, CSS3 and JavaScript**. Visitors can browse events, check the schedule, view the gallery, register for events and contact the organisers on any device.

## Features
- Landing page with a live countdown to the fest
- Announcements that can be updated dynamically
- Event cards with a category filter (Tech, Cultural, Sports, Fun)
- Date and time-wise schedule table
- Responsive gallery with a lightbox view
- Registration form with validation, error messages and a success message
- Duplicate registration check and a live registrations table
- Contact page with an enquiry form
- Mobile-friendly navigation menu

## Technologies
| Technology | Use |
|---|---|
| HTML5 | Semantic structure, forms, tables |
| CSS3 | Grid, Flexbox, media queries, animations |
| JavaScript | DOM manipulation, events, validation, dynamic updates |

## Project Structure
```
index.html   - page structure
style.css    - styling and responsive layout
script.js    - events, validation and dynamic content
```

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any browser.

## Responsive Testing
Open DevTools (F12), turn on the device toolbar and check 375px, 768px and 1280px widths.
